# ⚡ vaned

> **vaned** (*Vane Editor*) - a fast, minimal TUI text editor for linux.

## 📖 About

`vaned` is a terminal-based text editor built from scratch in Rust. It was born out of a desire for a straightforward, responsive tool that doesn't get in your way with complex keybindings or bloated configurations.

It is designed to be the default text editor for the **MNU** (*MNU's Not Unix*) ecosystem - a set of performance-focused, human-centric CLI tools.
